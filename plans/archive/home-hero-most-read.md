# หน้าแรกใหม่: ปกเต็มจอ + แถบ "แนะนำให้อ่าน" (เฟส 17–19) — เสร็จแล้ว

หมายเหตุ: ไฟล์แผนต้นทาง `plans/pending/home-hero-most-read.md` ไม่มีอยู่ใน repo ตอนย้าย (ไม่มีโฟลเดอร์ `plans/` เลย) ไฟล์นี้จึงเป็นสรุปงานที่ทำ ไม่ใช่ไฟล์ที่ย้ายมา

## สิ่งที่ทำ

**เฟส 17: เตรียมข้อมูล** (`scripts/build.mjs`, `.pages.yml`)
- `read_min` ใส่ใน `data/articles.json` ทุกเรื่อง คำนวณแบบเดียวกับหน้าบทความ (`Intl.Segmenter` ไทย, ไม่รวมแหล่งอ้างอิง/ช่องรอข้อมูล, `art.wpm` ภาษาไทย)
- front matter ใหม่ `pick` (1–10, ไม่บังคับ) และ `covers[].focus` (center|top|bottom|left|right) บันทึกใน `.pages.yml` พร้อมคำอธิบายไทย
- build ล้มเมื่อบทความ published ใช้ `pick` ซ้ำหรืออยู่นอก 1–10 หรือ `focus` ผิดค่า

**เฟส 18: ปกเต็มจอ** (`hero.js`, `hero.css`)
- featured ก่อน แล้วเรื่องใหม่สุด ไม่เกิน 5 เรื่อง เฉพาะที่มีปก `type: image`
- แถบเลือกเรื่อง + ลูกศรบนคอมพิวเตอร์ จุด + ปัดบนมือถือ เปลี่ยนเองทุก 6 วินาที หยุดเมื่อ hover/โฟกัสคีย์บอร์ด/แท็บซ่อน/พ้นจอ/ลดการเคลื่อนไหว

**แถบ "แนะนำให้อ่าน"** (`picks.js`, `picks.css`)
- ตามช่อง `pick` (ถ้ามี) ไม่เช่นนั้นเรื่องใหม่สุด ไม่เกิน 10 การ์ด ต้องมีตั้งแต่ 2 เรื่อง เลื่อนด้วย scroll-snap

**เฟส 19: จัดหน้า**
- ลำดับ: header → ปก → แถบแนะนำ → ปุ่มกรอง + รายการล่าสุด (เต็มความกว้าง) → อ่านตามหมวด → กล่องพอร์ตโฟลิโอ
- เอา `.topbar` ออกจากหน้าแรก, `#lead-main` ซ่อนไว้เป็นตัวสำรอง
- เมนูหลักแบบกรอบมนทุกหน้า (>860px)

## ผลตรวจ
- Lighthouse หน้าแรก (ก่อนเฟส 17 → หลัง): มือถือ Performance 95 → 96, Accessibility 100 → 100; คอมพิวเตอร์ 100 → 100, 100 → 100 (CLS 0.002)
- ไม่มี scroll แนวนอนที่ 375 / 768 / 1280 px ทั้ง 14 หน้า ไม่มีไฟล์ที่โหลดไม่ได้ ไม่มี error ใน console
- ใช้คีย์บอร์ดอย่างเดียวได้ครบ ลำดับ Tab เป็นเหตุเป็นผล

## ความต่างจากต้นแบบ `home-hero-preview`
1. เวลาอ่านมาจาก `read_min` ใน `articles.json` (ต้นแบบโหลดหน้าบทความทุกเรื่องมานับคำ)
2. ข้อความทุกอย่างผ่าน `i18n.json` + `bi()` สลับ TH/EN ได้ (ต้นแบบเป็นไทยตายตัว) หัวเรื่องในปกเขียนซ้ำเมื่อสลับภาษา เพราะต้องห่อคำที่มีขีดด้วย `span`
3. แถบแนะนำใช้ช่อง `pick` (ต้นแบบเรียงตามลำดับรายการ) เรื่องที่ไม่มีรูปปกขึ้นเป็นบล็อกดำ (ต้นแบบข้ามไป)
4. จองพื้นที่แถบแนะนำด้วยการ์ดเปล่า (ต้นแบบไม่จอง ทำให้ CLS บนมือถือ 0.257 และคะแนนตกเหลือ 83)
5. หยุดปกเมื่อชี้เมาส์หรือโฟกัสด้วยคีย์บอร์ดเท่านั้น (ต้นแบบหยุดตอนโฟกัสทุกแบบ ทำให้คลิกแท็บแล้วหยุดถาวร) ปัดถูกยกเลิกเมื่อเบราว์เซอร์ใช้เลื่อนหน้าเอง
6. ปุ่มจุดสูง 44px (ต้นแบบ 28px) ปุ่มเมนูแคปซูลสูงขึ้นเล็กน้อย (padding 10px ต้นแบบ 8px) ตามกฎขนาดปุ่ม
7. การเคลื่อนไหวทั้งหมด (เฟด ซูมภาพ เส้นความคืบหน้า ยกการ์ด) อยู่ใน `prefers-reduced-motion: no-preference`
8. กฎเมนูแคปซูลอยู่ใน `style.css` ใช้ทุกหน้า (ต้นแบบอยู่ในไฟล์ CSS ของหน้าแรก)
9. บทความเด่นแบบเดิมยังอยู่เป็นตัวสำรองเมื่อไม่มีปกรูปจริง
