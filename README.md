# The Picture

เว็บไซต์บทความ โปรเจกต์ และพอร์ตโฟลิโอของ กรวิชญ์ บัวดำ เขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

## โครงสร้างไฟล์

```
the-picture/
├── index.html                  หน้าแรก (บทความ)
├── articles/
│   └── crispr-alphafold.html   หน้าบทความ 1 เรื่อง = 1 ไฟล์
├── projects.html               หน้าโปรเจกต์
├── portfolio.html              หน้าพอร์ตโฟลิโอ
├── about.html                  หน้าเกี่ยวกับฉัน
└── assets/
    ├── css/style.css           สไตล์ทั้งเว็บ (สีหลักแก้ที่ --accent)
    └── js/main.js              ปุ่ม TH/EN, ค้นหา, ตัวกรอง, สารบัญ, แถบความคืบหน้า
```

## เพิ่มบทความใหม่

1. คัดลอก `articles/crispr-alphafold.html` เป็นไฟล์ใหม่ เช่น `articles/organoid.html`
2. แก้ชื่อเรื่อง คำโปรย หมวด เนื้อหา และสารบัญ (ลิงก์ `#id` ในสารบัญต้องตรงกับ `id` ของหัวข้อ)
3. ใน `index.html` เพิ่มรายการใน "ล่าสุด" และใส่ `data-cat` ให้ตรงหมวด (`medicine`, `biotech`, `bioinformatics`, `ai`, `notes`)
4. ใน `assets/js/main.js` เพิ่มบทความในตัวแปร `index` เพื่อให้ค้นหาเจอ

## ช่องที่ต้องเติม

ข้อความในวงเล็บ `[ ]` คือที่ว่างรอข้อมูลจริง เช่น รูปโปรไฟล์ ปีที่ได้รางวัล ชื่อรายการแข่งขัน ภาพกิจกรรม เกียรติบัตร อีเมล ลิงก์ GitHub และลิงก์ของแต่ละโปรเจกต์ (ตอนนี้เป็น `href="#"`)

## ขึ้น GitHub Pages

1. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ Settings → Pages แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`
3. รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`
